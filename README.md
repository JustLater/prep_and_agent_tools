# prep_and_agent_tools

## Предобработка


В рамках первичной обработки анкетных данных, предусмотрена классификация и группировка вопросов по ответам работников, для адаптации последующих аналитических процедур к специфике каждой группы. В частности, ответы делятся на три группы: тестовые (ответы, полученные путем выбора из фиксированного списка), в свободной форме, которые далее будут называться NLP-ответами (например, ответы на вопрос «Что вызвало трудности в X?») и ответы в малом количестве (они не предоставляют достаточно информации для анализа). Дополнительно в отдельную категорию выделяются длинные ответы, состоящие из k слов. Количество слов регулируется.


Первая группа кодируется, а NLP-ответы  проходят процесс многоэтапной обработки, включающий исправление орфографических и пунктуационных ошибок, лемматизацию, а также векторизацию. Исправление опечаток и векторизация реализуются с помощью специализированных моделей.


## Анализ данных

При анализе данных используется агентный подход, в ходе которого LLM-агенту предоставляются следующие инструменты: определение коэффициента корреляции Пирсона и кластеризация данных с помощью К-средних.


В отношении тестовых данных корреляционный анализ Пирсона применяется для идентификации следующих взаимосвязей:


1.  влияние конкретных вопросов на целевой столбец;
2.  зависимости целевого столбца от плотности ответов в столбце;
3.  взаимосвязи между ответами в тестовых столбцах.


Для NLP-ответов коэффициент корреляции обобщается на характеристики лексики: вычисляется зависимость целевого столбца от употребления конкретных слов.


Кластеризация K-средних применяется исключительно к NLP-ответам с целью группировки их в кластеры по семантической близости и, как следствие, выявления схожих паттернов, а также интерпретации их в контексте целевой переменной.
